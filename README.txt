PUBLICAR NO GITHUB PAGES

1. Extraia este ZIP. Envie os arquivos extraidos, nao o ZIP.
2. Crie um repositorio publico chamado portfolio.
3. Em Add file > Upload files, envie os arquivos e a pasta assets.
   index.html deve ficar na raiz do repositorio.
4. Confirme em Commit changes na branch main.
5. Em Settings > Pages, selecione Deploy from a branch.
6. Escolha main e /(root), depois Save.
7. Aguarde e abra o endereco mostrado pelo GitHub.

O site e as imagens ficarao publicos. Alteracoes na versao do ChatGPT
nao sao sincronizadas automaticamente com o GitHub.
